Everlast

by Sarekrn

Spell timers, voice alerts, maps, a DPS meter and raid helpers for Project 1999 EverQuest. Written for Linux in plain Python, so there is no Wine or .NET for the tool itself. It only reads your log file.

What it does

Everything below can be switched off in Settings. Use only what you want.

Spell and buff timers

  • Correct Project 1999 buff durations, with the DoT extra tick
  • Separate windows for buffs, mob debuffs and respawns
  • Recast timers and your own custom timers

Alerts you can see and hear

  • Big transparent banner, with the colour and size you choose
  • Computer voice, plus recorded clips for charm break, root break and buff faded
  • Fizzles, interrupts, buffs fading, group invites, watched spells, pansy trap

Maps

  • Detects your zone and shows the right map automatically
  • Zone search, z-level filter, mob names, follow-me

Raid helpers

  • Dragon Roar countdown, enrage and Death Touch warnings
  • Timers for raid mobs' zone-wide spells
  • Boat timers, Ring War rounds and a CH chain tracker with a "you are next" warning
  • Mana Sieve counter per mob, for enchanters

Custom triggers

  • "When this log line appears, show this and say that"
  • EQTool's 15 built-in triggers included
  • Import and export EQTool trigger files

Made for playing

  • Lock overlays so clicks pass through to the game, with per-window opacity
  • KOS or SAFE spoken when you /consider a mob
  • DPS meter with per-fight history
  • Follows the character you are playing; sits in the system tray

Install

Linux with Python 3 and Tk. An X11 session works best.

  1. Install Tk for Python:
    DistroCommand
    Debian / Ubuntu / Mint / Popsudo apt install python3-tk
    Fedorasudo dnf install python3-tkinter
    Arch / Manjaro / SteamOSsudo pacman -S tk
    openSUSEsudo zypper install python3-tk
  2. Download the latest release, unzip it, and run: 
    cd everlast
./install.sh      # optional: adds an "everlast" command and an app-menu entry
./everlast
  3. In game, turn logging on: type /log on (or set Log=TRUE in eqclient.ini). Every character you play needs it.
  4. For spoken alerts, install a voice: sudo apt install espeak-ng (Debian family).

On first start Everlast looks for your EverQuest folder (Wine, Lutris, Bottles, Steam/Proton, ~/Games). If it can't find it, Settings opens so you can pick the folder that holds eqgame.exe and spells_us.txt.

Questions

Does it work on Windows or macOS?

Not at the moment. Everlast is built and tested for Linux. A Windows version may come later.

Does it touch the game?

No. It only reads the eqlog_<character>_<server>.txt file that EverQuest writes, the same way EQTool does. It never reads game memory or sends anything to the game.

Nothing shows up for one of my characters.

That character's logging is probably off. Type /log on in game on it. Everlast's status line tells you when the log it follows has been silent for a while. Tools → Character log lets you pick a character's log by hand.

The overlays won't let me click through, or opacity does nothing.

Click-through and transparency need an X11 session with a compositing window manager. On Wayland, X11 apps run through XWayland and some of this can't work. Tools → Diagnostics explains what your desktop allows.

Is this an official tool?

No. Everlast is a fan project. It is not affiliated with Project 1999, Daybreak Game Company or EQTool.

Testing and feedback

Everlast is in beta and I am looking for testers, especially on desktops other than Cinnamon. If something breaks, please open an issue and include your distro, desktop, the version shown in the main window and what you expected to happen. The log file ~/.cache/eqtool-native/eqtool.log helps a lot.
